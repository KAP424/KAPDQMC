# 目标：不同构型对测量后纠缠熵的影响 —— 找规律并分类

## 物理背景（已确立，不要重测）

强测量（β 大）下固定 L 的熵展开精确成立：

    S2(R;β) = A_R(P,R) e^{-4β} + O(e^{-8β})

所以 A_R 是**只依赖初态构型 P 与区域 R** 的 β 无关泛函。区域取
A = (L/3)×L、C = L×(L/3)、B = (L/3)×(2L/3)，角组合 D_A = (2A_A + A_C)/3 − A_B。

    A_R = 2( ||X[E∩R, F∉R]||² + ||X[E∉R, F∩R]||² ),  X = Q_E Q_F^{-1}

## 本轮要回答的问题

1. 构型 P 怎样影响 A_R？能不能用一个**标量**刻画？
2. 已有分类（按原胞占据 class 1/2/3）是不是正确的分类轴？
3. 能否给出一条**定量规律**，把构型分成少数几类？

## 已得到的线索（run 1）

- m=2 的全部 70 个半满构型已枚举（无抽样偏差）。
- **占据 class 与 s_min 无关**：class 1 的 s_min 跨 0.0044–0.7071（‖X‖ 1–230）。
  即已有分类轴不是控制量。
- ‖X‖ = sqrt(s_min^{-2}−1) 在 m=2 只取 **6 个离散值** → 构型自然分族。
- **面积律系数 = 核的一阶矩**：
      momx = Σ_{a∈E,b∈F} Σ_δ |X_ab(δ)|² · min(|δx|, L/3)
      a_R = A_A/L ≈ 2 · momx        （比值 1.98–2.00，大 ‖X‖ 处降到 1.79）
  这是精确几何：直条带边界的穿越对数恰为 L·min(|δx|,L/3)，故 A_A = 2L·momx。
- 同一 ‖X‖ 族内 momx 仍差 3 倍 → ‖X‖ 是粗标签，momx 才是控制量。

## 工作规则

- 构型枚举必须**完整或确定性抽样**（禁随机），保证分类无选择偏差。
- L 必须满足 L = 3m·整数（`neq.md` 的协议可公度性），否则区域边界切穿原胞。
- 判定"不可测"用 s_min < 1e-8（Q_F 奇异），记为 obstructed 而非静默丢弃。
- 规律必须**可反驳**：给出预测值与实测值的最大相对偏差，并给出护栏。
